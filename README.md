# Sala Company — Start Page

**Live: [go.sala.company](https://go.sala.company)**

The start page for all of Sala Company's browser projects: live world news, market heatmaps, games and AI tools. Everything is free and runs in the browser, with no install and, except for Scene to Story's AI, no sign-up. Almost all of it was vibe coded from the start: built by describing it to an AI and refining it together, rather than written line by line.

[![The go.sala.company start page](og-image.png)](https://go.sala.company)

## How the page works

- **One file, no build step.** Everything is in `index.html`: plain HTML, CSS and JavaScript with no dependencies. GitHub Pages serves it at `go.sala.company` (see `CNAME`), and every push to `main` goes live in about a minute.
- **Top of the page:** a sticky bar (search, **Surprise me**, which opens a random app, and the theme button), then the hero: a headline and a **featured carousel** of 3–5 hand-picked slides. Each slide is a plain link with its own one-line pitch, so the first one shows without JavaScript; the rest advance every 6 seconds, pausing on hover, focus or reduced motion.
- **Just added:** a row of square thumbnails built from every card whose `data-added` date is in the last 45 days, newest first. It hides while searching or filtering.
- **Sections:** Live right now, Games, AI, Watch & listen and Create, each an `<h2>` with its own colour dot; every card title is an `<h3>`. The newsletter, store and About sit in cards below the grid.
- **Search and filters:** the search box matches card titles, text and each item's `data-tags`. The filter buttons (`aria-pressed`) show one section and show how many apps it has. Empty sections hide. Pressing Enter in the search box jumps to the results. A link like [`go.sala.company/?q=heat`](https://go.sala.company/?q=heat) opens with that search applied.
- **Cards:** one size for everything: a 16:10 screenshot, the title, **one line** of text and up to two small tags (`Phone`, `Your AI key`, `Needs WebGPU`…; phones show only the first). The title link covers the whole card, so a click anywhere opens the project. Extra links (Heat's markets) sit above it and stay clickable.
- **Badges:** **New** appears on its own for 30 days after a card's `data-added` date. **Beta** is written by hand while a project is a work in progress.
- **Live headline:** the Sala News card shows the top story from `news.sala.company/breaking.json` (which allows reading from other sites). If it can't load, the card keeps its plain line of text.
- **Counts:** the "22 free apps" pill, the search placeholder and the filter counts are worked out from the cards, so they stay right as apps are added.
- **Theme:** light and dark follow the system. The ◐ button cycles Auto → Light → Dark and remembers the choice in that browser.
- **Font:** Inter (`fonts/inter-latin.woff2`), hosted here so the page makes no calls to Google, as on heat and news.

## Adding or changing a project

1. **Card:** copy an `<li class="item">` in the right section of `index.html` and change the link, title, one line of text, tags, `data-tags`, screenshot and `data-added` (the launch date, `YYYY-MM-DD`). That one date gives it the New badge and a place in Just added.
2. **Screenshot:** save a 640×400 JPEG as `img/<project>.jpg`. The current ones were taken with headless Edge at 1280×800, then cropped and scaled:
   ```
   msedge --headless=new --hide-scrollbars --window-size=1280,800 --virtual-time-budget=10000 --screenshot=shot.png https://example.sala.company
   ```
3. **Structured data:** add the project to the `ItemList` in the JSON-LD at the top of `index.html`, in page order, and update `numberOfItems`.
4. **What's new:** add a line to this README. To put it in the carousel, swap one of the hero's `.slide` links for it.
5. **Dates:** set `dateModified` in the JSON-LD and `lastmod` in `sitemap.xml` to today.
6. **Link preview (optional):** if the top of the page changed, retake `og-image.png` at 1200×630.

## Search engines and link previews

- **Title and description** written for search results, within Google's display limits.
- **Canonical URL** `https://go.sala.company/`, plus Google and Bing site-verification tags.
- **Link previews** (Open Graph and X): `og-image.png`, a 1200×630 screenshot of the page.
- **Icons:** the "S" mark in `favicon.svg`, with `favicon-48.png` and `favicon.ico` for browsers and search results, and `apple-touch-icon.png` (180×180, square; phones round the corners) for home screens.
- **Structured data** (JSON-LD): the `WebSite` with its search (`?q=`, which really works), the `WebPage` (with `dateModified`), the `Organization`, and an `ItemList` of every project in page order, each a free `WebApplication`, `VideoGame` or `WebSite` with its own description and screenshot.
- **Crawlable text:** the cards, the carousel slides and an About / FAQ section give search engines plain text about each project, and are all visible without JavaScript.
- **`robots.txt`** and **`sitemap.xml`**.
